# FlagsBattle — Full Game V1

## Included
- 10-country flag pool
- Classic, Speed Battle and Chaos modes
- Physics-style bouncing and collisions
- Click/tap support system
- Live scoreboard
- Timer
- Pause/resume
- Reset score
- Winner screen
- Responsive mobile/desktop UI
- Node.js + Socket.IO backend scaffold for real-time events
- `/health` endpoint

## Run locally
1. Install Node.js
2. Open this folder in terminal
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

## YouTube Live
The backend is prepared for a future YouTube Live Chat bridge. A secure server-side YouTube OAuth/API integration should be added before production. Never put a YouTube private credential or OAuth secret in the browser.
